# Changelog

## 1.0.10

- Shift+left-click on an item links it in the chat box you have open.
- Ctrl+left-click on an item previews it in the dressing room.
- Both work like the default vendor window, on the Buy Back tab too.

## 1.0.9

- Hovering an item shows the default vendor cursor: the coloured bag when you can buy it, the greyed-out bag when you can't (too expensive, out of stock or not for sale).
- Right-click now buys one full vendor bundle: an item sold as "200" on the icon gives you 200, not 1.
- The quantity dialog now handles items a vendor sells in bundles (for example ammo in stacks of 200): the number you enter counts purchases, and the dialog shows how many items you will receive.
- Limited vendor stock is now counted in purchases, and large orders are split into whole bundles.

## 1.0.8

- Buying now follows the default vendor window: right-click buys one item, Shift+right-click opens the quantity dialog. Right-click on the Buy Back tab buys the item back.

## 1.0.7

- Packaging and repository housekeeping only; no changes to how the addon works.

## 1.0.6

- Items your character can't use now show a red "Can't use" note and a red-tinted icon.

## 1.0.5

- New addon icon: a detailed pixel-art treasure chest.

## 1.0.4

- Other panels (Character, Bags, ...) no longer open offset to the right when the vendor window is open; the hidden default vendor frame no longer reserves screen space.

## 1.0.3

- Added an original addon icon, shown in the in-game addon list.

## 1.0.2

- Widened the "Only usable" and "Hide known" toggles so their labels are no longer cut off.

## 1.0.1

- Slot filter is now a compact multi-column picker that stays inside the window, instead of a long dropdown list.
- One-hand, two-hand and ranged weapons are grouped under a single "Weapons" entry; shields and off-hands stay under "Off Hand".

## 1.0.0

- Replaces the default vendor window with a centered window in the Forever bronze style.
- Item grid with 4 columns and paging; the mouse wheel flips pages.
- Tabs: All Items, Usable and Buy Back.
- Search box that filters items by name.
- Slot filter (Head, Chest, Trinket, Weapons, and so on). Recipes are matched by the slot of the item they craft.
- Saved toggles: "Only usable" and "Hide known" (already-known recipes, pets, toys).
- Buy any quantity, beyond the stack size: Shift+click opens a dialog with the total cost. A plain click buys one.
- Supports gold, currencies and item costs. The footer shows how many of each currency the vendor asks for you hold, and unaffordable costs are shown in red.
- Repair All button with the repair cost.
