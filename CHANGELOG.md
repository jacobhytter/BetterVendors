# Changelog

## 1.0.0

- Replaces the default vendor window with a centered window in the Forever bronze style.
- Item grid with 4 columns and paging; the mouse wheel flips pages.
- Tabs: All Items, Usable and Buy Back.
- Search box that filters items by name.
- Slot dropdown (Head, Chest, Trinket, weapons, and so on). Recipes are matched by the slot of the item they craft.
- Saved toggles: "Only usable" and "Hide known" (already-known recipes, pets, toys).
- Buy any quantity, beyond the stack size: Shift+click opens a dialog with the total cost. A plain click buys one.
- Supports gold, currencies and item costs. The footer shows how many of each currency the vendor asks for you hold, and unaffordable costs are shown in red.
- Repair All button with the repair cost.
