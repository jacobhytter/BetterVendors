# BetterVendors

Replaces the default vendor window with a centered, searchable item grid that matches the look of the Forever addons. Made for World of Warcraft Forever.

## Features

- Centered window, 4 columns of items, mouse wheel flips pages
- Tabs: **All Items**, **Usable**, **Buy Back**
- **Search** by item name
- **Slot** filter (armor slots, Weapons, Off Hand). Recipes are matched by the slot of the item they craft
- Saved toggles: **Only usable** and **Hide known** (already-known recipes, pets, toys)
- Buy **any quantity**, beyond the stack size, with the total cost shown first
- Works with gold, **currencies** (for example Merchant's Favor) and item costs. Your current amount of each currency the vendor asks for is shown in the footer, and costs you cannot afford are red
- **Repair All** with the repair cost

## Usage

| Action | Result |
|---|---|
| Right-click an item | Buy one (like the default vendor window) |
| Shift+right-click an item | Open the quantity dialog (**Stack** and **Max** shortcuts) |
| Mouse wheel | Previous / next page |
| ESC or the X button | Close the vendor |

## Requirements

SharedForeverUI2 must be installed. It supplies the window, tab and button styling.

## Notes

- The default vendor window is hidden while BetterVendors is enabled. Disable the addon to get it back.
- Currency and item costs are bought without Blizzard's extra confirmation popup, so the quantity dialog (Shift+right-click) is the safer way to make large purchases.
